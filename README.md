Phishing Detection Tool

A Python-based tool designed to analyze URLs and identify suspicious indicators commonly associated with phishing attacks.

Features

- HTTPS usage analysis.
- IP address detection.
- Suspicious keyword detection.
- URL length analysis.
- URL shortener detection.
- Punycode detection.
- Suspicious subdomain detection.
- Brand impersonation detection using string similarity.

Technologies

- Python
- URL Parsing
- IP Address Validation
- String Similarity
- JSON

Usage

Run the tool using:

python phishing_detector.py

Enter a URL to receive an analysis report containing the risk score, risk level, and detected indicators.

The results are also saved in a JSON file.

Project Purpose

This project was developed to practice Python programming and explore basic techniques used in phishing URL analysis.
